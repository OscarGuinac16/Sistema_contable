# Sistema_contable

## Summary:

- El objetivo principal de este diseño no solo guardar datos, sino construir un modelo relacional lo suficientemente robusto para extraer información  estratégica. 
Al normalizar la información, resolvemos el problema de los datos aislados. Esto nos permite ejecutar consultas dinámicas y conectar fluidamente los distintos módulos del sistema, como la logística, el inventario y las finanzas, para armar los reportes exactos que un departamento contable necesita en su día a día.
